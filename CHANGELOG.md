# Changelog

## 1.1.0 · Community feedback round

This release expands WildMinute from a tiny activity suggester into a full plan-record-reflect loop.

- Added a manually entered area / starting point and activity preferences.
- Added generated flexible route outlines and context-aware things-to-look-for prompts.
- Added an offline-ready, per-adventure checklist with persistent checkmarks and print support.
- Added local field notes with observation types and compressed photo attachments.
- Added local-AI Adventure Journal generation, with a transparent on-device template fallback.
- Added an archive of saved journals, text export, and share/copy actions.
- Kept route claims honest: no invented trail names, distances, live conditions, or claimed turn-by-turn navigation.
- Removed the Express dependency; the app now runs on Node's built-in HTTP server.
