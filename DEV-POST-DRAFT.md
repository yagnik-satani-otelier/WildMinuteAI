## What I Built

WildMinute is a local-first outdoor adventure planner. It asks how much time I have, my mood, the kind of outdoor activity I want, and an optional area or starting point. It then creates a short mission, a flexible walk outline, and a list of details to look for outside.

The community feedback pushed the project beyond activity suggestions. WildMinute now includes an offline-ready adventure checklist, local field notes with photos, persistent saved adventures, and an Adventure Journal generated from the notes after I return. The checklist and journal template continue to work when AI or the network is unavailable. There is no GPS permission or account, and the app is designed to keep its fieldbook on the device.

## How I Built It

WildMinute is a small dependency-free Node.js HTTP server with a responsive vanilla-JavaScript interface. For AI-generated missions, the server sends a structured prompt to Gemma 3 1B through Ollama running locally. The prompt asks for a bounded JSON result: a mission, short steps, one observation cue, a phone-away rule, a safety reminder, and a reflection question.

The prompt and parsing logic are visible in the repository, which means other builders can inspect the model's instructions, tweak the constraints, or swap in another Ollama-supported model. A second local-AI prompt turns a walk record into a short journal. Photos stay in browser storage and are not sent to the model. If the model is unavailable, WildMinute clearly labels built-in missions and the on-device journal template instead of pretending they were generated by AI.

The route feature is intentionally honest: it produces a suggested route *shape*, not fabricated street names or turn-by-turn navigation. It doesn't claim to check real-time maps, trail closures, accessibility, or weather. When an area is entered, the user can optionally open an external Maps search to choose and verify a real path.

## Why Does Open Innovation Matter?

For an app about reconnecting with the real world, the AI should not need to collect a person's location or ship their preferences to a remote service. With local inference, the model can help shape a useful activity on the user's own machine. There is no WildMinute API key, hosted inference bill, or account system to maintain.

Open weights and an inspectable prompt also make the behavior easier to change. Someone can adapt the tone, accessibility constraints, or activity rules to their context rather than treating a closed endpoint as a black box. The app's fallback keeps the interface explorable, but only the Ollama path is described as AI-generated.
